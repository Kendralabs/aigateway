# Kendra AI Gateway

## Versioning Policy (Semantic Versioning - SemVer)

This document will adhere to [Semantic Versioning (SemVer)](https://semver.org/) principles: `MAJOR.MINOR.PATCH`.

*   **MAJOR version (X.y.z):** Incremented for incompatible changes to the project's core vision, architecture, or key integrations.
*   **MINOR version (x.Y.z):** Incremented for adding new features, significant architectural additions, or expanding integration points in a backwards-compatible manner.
*   **PATCH version (x.y.Z):** Incremented for backwards-compatible bug fixes, clarifications, or editorial changes that do not alter core requirements or functionality.
