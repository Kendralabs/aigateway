# Product Requirements Documents (PRD) for Kendra Fabric UI

This directory contains the Product Requirements Documents (PRDs) for the Kendra Fabric User Interface. Each PRD outlines the scope, features, user journeys, and technical requirements for specific components or phases of the UI development.

## Document Naming Convention

PRD documents are versioned and named using the following convention:

`v[MAJOR].[MINOR].[PATCH]_[short_description].md`

**Example:** `v1.0.0_initial_ui_prd.md`

## Available PRDs

*   [v1.0.0_initial_ui_prd.md](v1.0.0_initial_ui_prd.md) - Initial PRD for Kendra Fabric UI

## How to Use

1.  **Review:** Read the relevant PRD to understand the requirements for a specific feature or phase.
2.  **Contribute:** Provide feedback, ask questions, and propose changes by collaborating on the Markdown files.
3.  **Update:** For significant changes or new phases, create a new versioned document or update an existing one, following the naming convention and updating the "Version History" section within the document and this `README.md`.
