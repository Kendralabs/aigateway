# AI Gateway MCP Project – Documentation Index

This folder contains the full product‑planning artefacts for the AI Gateway (MCP) service, including:
- **Epics** – high‑level objectives.
- **User journeys** – narrative flows for key personas.
- **Sequence diagrams** – mermaid‑based technical flows.
- **UX/UI definitions** – wire‑frame level UI specifications.
- **Jira mapping** – placeholder issue keys that can be imported into Jira.

> All files are written in plain Markdown and are organised under sub‑folders for easy navigation.
